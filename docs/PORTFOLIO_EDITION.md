# 作品集公开版说明

## 仓库定位

本仓库是 RegPilot 的**可运行公开作品版本**，用于招聘方独立审阅 AI 应用工程、法规证据处理、模型工具调用和本地工作台设计。它保留了可以脱离私有目录运行与测试的实现，但不等于完整生产系统，也不承诺生产可用性、法规结论权威性或企业系统兼容性。

公开版与完整本地原型共享核心交互和工具合同，但公开版把高风险或不可公开的集成替换为确定性模拟实现。路线图文档描述目标架构，不代表相应模块已经交付。

## 公开源码可运行和验证的能力

| 能力 | 公开版中的实际边界 | 验证方式 |
| --- | --- | --- |
| 本地法规工作台 | Loopback HTTP 服务、Web UI、会话创建/重命名/归档、SSE 流式事件、模型设置和本地持久化 | 启动器冒烟检查、HTTP/UI 测试、手动启动 |
| 法规资料证据处理 | 摄取用户明确提供的 `md/txt/html/json/jsonl/csv/docx/xlsx` 和文本型 PDF，生成证据 ID、定位信息、检索结果和受长度约束的证据包 | `test_source_documents.py`、`test_agent_skills.py` |
| 法规索引/来源台账 | 来源分组、处理状态、法规身份去重、状态历史、附件关系及 JSON/CSV 导出 | `test_regulation_index.py` |
| 法规解读产物 | 要求报告引用已登记的 Source Evidence，并生成 Markdown/DOCX 与清单文件 | `test_source_documents.py` |
| 模型运行时 | 用户自备 OpenAI-compatible API 的配置、流式文本/工具调用、重试、用量事件和错误归一化 | `test_model_runtime.py`、`test_formfill_chat.py`；真实调用需外部网络、凭据和可用模型 |
| Skills 与工具编排 | 本地 Skill 清单、候选选择、加载/校验，以及模型工具循环 | `test_agent_skills.py`、`test_formfill_chat.py` |
| 模拟填报 | 上海数据、OTA、地标三类演示任务的输入校验、人工介入合同和提交前停止；结果固定带 `demo_mode=true` | `test_portfolio_boundary.py`、`test_formfill_chat.py` |

未配置模型 API 时，工作台、会话管理、Skills 清单和规则驱动的模拟填报仍可运行。通过聊天自然语言驱动资料摄取、台账整理、报告生成与模型分析时，需要配置可用的模型；这些底层能力本身可由离线测试验证。

公开版保留了受控 Chrome 的 UI/API 合同以展示边界设计，但默认探测器始终返回未连接，默认启动器只返回作品版说明，不会创建浏览器进程。相关测试使用注入的测试替身，不表示公开版包含真实浏览器控制。

## 招聘方最短验证路径

环境要求：Windows 10/11、Python 3.11+。在仓库根目录运行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
.\.venv\Scripts\regpilot-launcher.exe --smoke
$LASTEXITCODE
```

预期结果：当前版本发现并通过 `153` 个测试，输出以 `OK` 结束；冒烟命令短暂启动随机 loopback 端口、读取首页后退出，`$LASTEXITCODE` 为 `0`，且不会打开浏览器窗口。

随后运行：

```powershell
.\.venv\Scripts\regpilot-launcher.exe
```

预期结果：默认浏览器显示 RegPilot 本地工作台，可创建和管理会话、查看 Skills 与运行状态。无需 API Key 即可输入以下合成演示指令：

```text
帮我用 <C:\RegPilotDemo\demo.xlsx> 的 C 列填报上海数据平台
```

预期返回 `final_review`/提交前复核语义，并明确提示“没有读取或写入真实工作簿”。该路径只是输入合同的合成占位值，文件无需存在，也不会被模拟填报器打开。

如需验证自然语言法规检索、台账和模型分析，可在设置中填入专用低权限测试 Key，再使用自有或公开授权的法规样例。模型提供方、网络与输入资料不由本仓库提供。

## 数据与隐私边界

- Git 跟踪内容不包含真实法规数据集、生产工作簿、Cookie、浏览器 Profile 或 API Key。测试中的 `D:\case\...`、`D:\ota\...` 等路径和密钥字符串是合成夹具，不是本机依赖或真实凭据。
- 默认运行状态写入 `%LOCALAPPDATA%\RegPilot\`，包括会话、资料解析结果、来源路径、法规索引、导出产物和模型设置。不要用隐私、客户或受限资料进行公开演示。
- `provider_settings.json` 中的 API Key 是本机明文 JSON 配置，不使用操作系统凭据保险库。只使用专用低权限测试 Key，演示后按需删除或轮换。
- 配置模型后，提问内容、工具上下文和选定证据会发送到用户配置的 `Base URL`。使用者负责确认模型提供方的数据处理、保留和跨境规则。
- HTTP 服务默认只绑定 `127.0.0.1`，没有公网认证层；不得直接暴露到局域网或互联网。
- 仓库资源通过仓库根目录或打包目录解析，不依赖父仓库。可选环境变量允许使用者显式覆盖状态、静态资源、Skills 和模型配置路径。
