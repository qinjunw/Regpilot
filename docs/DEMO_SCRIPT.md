# 演示脚本

建议时长：90 秒。

前置条件：使用可公开的合成法规样例；如需演示自然语言检索和分析，配置专用低权限模型测试 Key，并说明这是外部依赖。

1. 展示 README 的能力边界，说明应用本地运行。
2. 导入一份可公开使用的法规样例文件。
3. 搜索一个明确条款，展示命中的证据和来源。
4. 提问一个需要组合多条证据的问题，展示流式分析与引用。
5. 通过对话整理法规来源台账，展示状态历史和 JSON/CSV 导出路径或文件。
6. 使用合成工作簿路径触发模拟填报，展示 `demo_mode=true` 和提交前停止提示。
7. 结束时强调：当前版本不启动受控 Chrome、不读取生产填报工作簿，也不登录或提交任何第三方网站。

录制前请清空历史会话、API Key、真实文件名和本机路径。

完整本地原型的截图或视频可展示真实集成工作流，但必须明确标注其浏览器、工作簿、企业平台和生产填报适配器不包含在本公开仓库中。
